# Store images

Generated by `scripts/store-assets.ts` from screenshots of the REAL extension (`scripts/screenshots.ts`), using synthetic data.

* 1280×800 images: panel renders with a caption. They are **renders of the extension's side-panel page**, labelled as such in each image — Playwright cannot capture Chrome's docked side panel.
* `promo-small-440x280.png`: small promo tile.
* Regenerate after any UI change: `npm run screenshots && npx tsx scripts/store-assets.ts`.
* Before submitting, the owner should replace or supplement these with real window screenshots taken manually in Chrome.
