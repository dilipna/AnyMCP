## Tools, recorded through the real recorder

* https://books.toscrape.com (Books to Scrape (category listing)) — static HTML; part of the path is the input; results are links. Tool `books_in_category`, recorder picked `{"by":"css","selector":"article.product_pod > h3 > a"}`
* https://www.scrapethissite.com (Scrape This Site (hockey team search)) — query-string search form results; results are table rows. Tool `hockey_team_search`, recorder picked `{"by":"css","selector":"table.table"}`
* https://quotes.toscrape.com (Quotes to Scrape (JavaScript-drawn page)) — the raw HTML has no quotes; they are drawn by JavaScript after load; part of the path is the input. Tool `quotes_page`, recorder picked `{"by":"css","selector":"span.text"}`
* https://webscraper.io (Web Scraper test shop (laptop listing)) — a different site: product cards; the page number is in the query string; results are links; past the last page there are no cards and the run must stop. Tool `laptops_page`, recorder picked `{"by":"css","selector":"a.title"}`
* https://www.scrapethissite.com (Scrape This Site (countries, a long page with no input)) — one static page with 250 cards and no input; the tool returns the first 25 (its row cap). Tool `countries_list`, recorder picked `{"by":"css","selector":"h3.country-name"}`
* https://books.toscrape.com (Books to Scrape (one book's price)) — one value, not a list; part of the path is the input; a recommended-books strip below repeats the same price style, so the tool must return the book's own price. Tool `book_price`, recorder picked `{"by":"css","selector":"div.col-sm-6.product_main p.price_color"}`
* https://quotes.toscrape.com (Quotes to Scrape (layout table, by tag)) — quotes laid out with an HTML table used for layout: each quote is a cell in its own row and its tags are in the next row; part of the path is the input. Tool `quotes_by_tag`, recorder picked `{"by":"css","selector":"table > tbody > tr > td[style=\"padding-top: 2em;\"]"}`
* https://quotes.toscrape.com (Quotes to Scrape (drawn 10 seconds after load)) — the quotes are drawn by a 10-second timer after the page loads, longer than a recorded tool's 5-second step timeout; part of the path is the input. Tool `delayed_quotes_page`, recorder picked `{"by":"css","selector":"span.text"}`
* https://the-internet.herokuapp.com (The Internet (test-automation practice site, data table)) — another site, built for test-automation practice: a data table whose last column holds action links; no input. Tool `practice_table`, recorder picked `{"by":"css","selector":"#table1"}`
* https://the-internet.herokuapp.com (The Internet (large and deep page, 50 x 50 table)) — a large page (about 180 KB, 2,500 table cells, elements nested 50 deep); the table's headers are the numbers 1 to 50; every column kept; no input. Tool `large_table`, recorder picked `{"by":"css","selector":"#large-table"}`
* https://the-internet.herokuapp.com (The Internet (click Start, text drawn 5 seconds later)) — a click on a button, then text drawn 5 s later, exactly the default step timeout; no input. Tool `loading_message`, recorder picked `{"by":"css","selector":"div.example > div > h4"}`
* https://www.scrapethissite.com (Scrape This Site (click a year, films loaded by a request)) — a click on a year link (made an input), then a table filled by a request and drawn 1.5 s later; the address does not change. Tool `films_of_year`, recorder picked `{"by":"css","selector":"table.table"}`
